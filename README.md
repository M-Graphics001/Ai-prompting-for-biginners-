🤖 AI Prompting for Beginners

A simple, practical guide to learning how to write better prompts for Artificial Intelligence tools.

No programming experience is required.

📚 What You Will Learn

By completing this guide, you will learn:

- What Artificial Intelligence (AI) is
- What a prompt is
- How AI responds to instructions
- How to write clear prompts
- How to provide useful context
- How to set constraints and requirements
- How to request specific output formats
- Different prompting techniques
- Common prompting mistakes
- How to improve prompts through iteration
- How to create reusable prompt templates

🎯 Who Is This For?

This repository is designed for complete beginners.

You do not need to be a programmer or AI expert. If you can write a question or instruction, you can start learning prompting.

🧠 What Is Prompting?

Prompting is the process of giving instructions or information to an AI system to produce a desired response.

Basic prompt

Explain Python.

Improved prompt

Explain Python to someone who has never programmed before.

Use simple language, provide 3 real-world examples,
and finish with a short practice exercise.

The second prompt gives the AI more information about the task, audience, and desired output.

🧩 A Simple Prompt Formula

A useful starting formula is:

Task + Context + Requirements + Output Format

Example:

Task:
Create a study plan for learning Python.

Context:
I am a complete beginner and can study for 1 hour per day.

Requirements:
Make the plan last 30 days and include practice exercises.

Output:
Present the plan as a table.

⭐ The Golden Rule

Do not try to write a "magic prompt."

Instead:

Be clear. Give context. State your requirements. Specify the desired output. Review the result. Improve the prompt.

Prompting is an iterative process.

⚠️ Important

AI systems can produce incorrect, incomplete, outdated, or misleading information.

Always verify important information, especially when dealing with:

- Health
- Law
- Finance
- Security
- Academic research
- Important decisions

Never share passwords, private keys, confidential documents, or other sensitive information with an AI system unless you understand how that service handles your data.
